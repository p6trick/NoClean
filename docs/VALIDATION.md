# 공개용 사본 검증

2026-11-02에 수행한 배포 준비 검사다. 아래 소량 추론은 경로 분리와 모델 로딩의 동작 검사이며 전체 실험을 다시 수행한 성능 결과가 아니다.

| 검사 | 결과 |
|---|---|
| 기존 PyTorch 파이프라인 단위 테스트 | 27개 통과 |
| 새 manifest 경로 변환 테스트 | 3개 통과 |
| Python 코드 문법 검사 | 통과 |
| 공개 폴더의 모델·데이터 바이너리, 대용량 파일, 개인 작업 경로 검사 | 통과 |
| 별도 폴더의 가중치 | 29개 존재·크기·SHA256 일치 |
| 선택된 평가 manifest의 clean/attack 파일 존재 | 고유 파일 43,750개, 누락 0개 |
| 분리된 가중치/데이터 루트로 N2N 소량 추론 | MNIST 공격별 8장, LivDet 공격별 1장, 각각 6개 공격 완료 (CPU) |
| 별도 AT 폴더로 Keras 모델 로딩·추론 | LivDet/MNIST FGSM 각 1장 완료 (CPU) |

데이터 검사는 파일 존재만 확인했으며 이미지 전체의 해시를 다시 계산한 검사는 아니다. 전체 성능 표는 기존 실행의 집계를 보존했다. 코드에 포함한 GitHub Actions는 외부 데이터·가중치를 요구하지 않는 소스 검사만 수행한다.

## 별도 이미지 복사본

같은 날 `N2N_data`에 이미지 167,500장과 MNIST 순서 파일 1개를 복사했다. 이 수집 과정에서는 **모든 파일의 원본·복사본 SHA256을 비교**했고, 원본 파일은 유지했다. 복사 후 167,501개 파일의 존재·크기도 다시 확인했다. 파일별 해시는 데이터 묶음의 `files.csv`, 결과는 `collection.json`과 `validation.json`에 있다.

복사본만 가리키는 경로로 MNIST 전체 학습·검증·평가 입력과 목표, LivDet 6개 공격의 분할·목표 경로 및 기존 평가 ID 대응, 저장 DIP 4개 공격의 평가 ID를 확인했다. 같은 경로로 MNIST 공격별 8장과 LivDet 공격별 1장의 N2N 추론도 완료했다. 이미지의 손상 여부를 새로 판정하거나 재인코딩한 검사는 아니다.
